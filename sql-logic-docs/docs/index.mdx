## 产品能力

<div className="feature-grid">

<div className="card" style={{padding:'20px'}}>

### ⚙️ 工作流编排

节点式画布（DataScience、DatabaseResource、Agent 等），支持连接级联、Schema/Table 探测与节点间数据流转。

</div>

<div className="card" style={{padding:'20px'}}>

### 🤖 Agent 执行

单 Agent 与多 Agent（agentic workflow）两种模式，内置执行时间线、Markdown 渲染输出与可读结果回显。

</div>

<div className="card" style={{padding:'20px'}}>

### 🗄️ 数据源接入

DatabaseMetaDataService 自动拉取真实表清单与 DDL，支持连接 → Schema → Table 级联选择。

</div>

<div className="card" style={{padding:'20px'}}>

### 📊 LLM 监控

`llm_call_metrics` 数据层统一上报，Admin 控制台提供工作流概览、Agent 步骤指标与令牌统计。

</div>

<div className="card" style={{padding:'20px'}}>

### 🛡️ 独立 Admin 控制台

`sql-logic-admin`（端口 3001）独立 Vite 应用，Dashboard / Workflows / LLM Monitor 多视图。

</div>

<div className="card" style={{padding:'20px'}}>

### 🎨 Linear 风格 UI

统一 `#5b7fd9` 主色调，明暗双模式，Inter + JetBrains Mono 字体栈，动效平滑。

</div>

</div>
