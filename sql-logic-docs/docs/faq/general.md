# 高频问题

## 产品与定位

### 文档站和 Swagger 是一回事吗？

不是。本站是**产品使用手册**（怎么用），由 Docusaurus 构建；Swagger 是后端自动生成的**接口契约**（怎么调）。两者分开，详见 [API 概览](/docs/api/overview)。

### 主客户端和控制台是什么关系？

两个独立的应用：

- **主客户端**（端口 3000）—— 用来设计、运行工作流。
- **控制台**（端口 3001）—— 用来回看执行、监控指标。

它们共享同一个后端，但互不依赖，可分别启动。

### 我需要会写 SQL 吗？

不需要。Agent 节点理解自然语言，你只需用大白话描述想要什么，Agent 会生成并执行 SQL。当然，如果你懂 SQL，可以把提问写得更精准，效果更好。

## 工作流与 Agent

### 单 Agent 和多 Agent 怎么选？

先用单 Agent。当你的问题包含「先……再……」、且后一步依赖前一步结果时，再升级为多 Agent 工作流。详见 [Agent 执行](/docs/guide/agent-execution)。

### 为什么数据节点是下拉选表，而不是填表名？

为了准确。下拉里的表清单是引擎实时从数据库拉取的，既不会拼错表名，也能让你直观看到库里有什么。详见 [核心概念 - 连接](/docs/constructure/concepts)。

### 执行结果为什么有时候是 JSON？

当 Agent 的输出无法解析为 Markdown 时，会回退显示原始 JSON，保证信息不丢失。通常意味着 Agent 的提问需要写得更具体，或者结果结构不适合表格化呈现。

### 时间线出现重复节点怎么办？

正常情况下不会。结果卡片用稳定的节点 ID 作为标识，状态切换时不会重复。如果遇到，确认你使用的是包含该修复的版本，并参考 [排错指引](/docs/faq/troubleshooting)。

## 监控与运维

### 控制台里 Agents 数据为什么是空的？

Agents 视图的数据来自多 Agent 工作流。如果你只跑了单 Agent 工作流，这里可能为空，属正常现象。

### 状态徽标颜色代表什么？

- 🟢 绿色 = 成功
- 🔴 红色 = 失败
- 🟡 黄色 = 运行中或状态未知
